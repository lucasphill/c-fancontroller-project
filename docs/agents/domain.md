# Documentação de domínio

Este projeto tem um único contexto.

Antes de explorar uma área, leia GLOSSARY.md e os documentos
relacionados em docs/adr/, quando existirem.

Use os termos definidos no glossário.
Informe explicitamente quando uma proposta contrariar um ADR.

Crie o glossário conforme os termos forem definidos.
Registre ADRs apenas para decisões com alternativas relevantes,
custo significativo de reversão e justificativa necessária.
