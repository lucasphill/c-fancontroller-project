# Pendências locais

Uma pasta por funcionalidade: .scratch/<funcionalidade>/.
A especificação fica em spec.md.
Cada tarefa fica em issues/<NN>-<descricao>.md, numerada desde 01.

Registre a classificação na linha Status:, usando triage-labels.md.
Acrescente comentários ao final, em uma seção Comments.

Publicar uma pendência significa criar seu arquivo local.
Consultar uma pendência significa ler o arquivo correspondente.
